# SHM Physics Simulator

Interactive Simple Harmonic Motion simulator built with Streamlit, NumPy and Plotly.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run main.py
```

## Deploy on Streamlit Community Cloud

1. Create a GitHub repository and upload `main.py`, `requirements.txt`, and this README.
2. Open https://share.streamlit.io/ and sign in with GitHub.
3. Select **Create app**, choose the repository and branch, and set the main file path to `main.py`.
4. Select **Deploy**. Share the generated app URL.
